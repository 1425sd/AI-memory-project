# Module Map

> 本文件是项目的模块导航索引，用来回答“某项功能属于哪个模块、代码在哪里、从哪里开始读”。系统级依赖规则见 `memory-bank/systemPatterns.md`，复杂模块内部说明见 `docs/modules/*.md`。

## 维护原则

- 使用目录或 glob 描述源码范围，例如 `src/modules/order/**`，不要逐个罗列普通实现文件。
- 只记录入口、公开接口、注册点、核心数据定义等关键文件。
- 代码是事实来源；文档与代码不一致时，先核对代码并更新文档。
- 无法确认的模块归属标记为“待确认”，不要根据文件名编造职责。
- 小型模块可以只出现在本文件；复杂模块再建立 `docs/modules/<module>.md`。

## 更新触发条件

出现以下情况时更新本文件：

- 新增、删除、拆分、合并或重命名模块
- 移动模块目录或改变源码范围
- 改变关键入口、公开接口或应用注册点
- 改变模块直接依赖或共享代码归属
- 测试、迁移、配置或外部服务适配入口发生变化
